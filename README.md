# 🛠️ PromptForge — Studio Local-First de Specs & Prompts IA

**PromptForge** est un studio de conception, de test et d'exportation de prompts et de spécifications d'agents IA (`CLAUDE.md`, `.cursorrules`, `AGENTS.md`, System Prompts).

Application web **100% local-first**, sans serveur, sans dépendances et sans compte.

## 🌟 Fonctionnalités

- **Éditeur avec Détection de Variables (`{{variable}}`)** : Détecte automatiquement les variables dynamiques et génère un formulaire de remplissage en direct.
- **Générateur Multi-Format** : Exportation 1-clic vers `CLAUDE.md`, `.cursorrules`, `AGENTS.md`, System Prompt ou JSON Spec.
- **Compteur de Tokens & Estimation du Coût** : Calcul en temps réel du nombre de tokens (Claude 3.5/3.7, GPT-4o, Gemini 2.0) et coût estimé par appel.
- **Bibliothèque de Presets d'Agents IA Prêts à l'Emploi** : Presets intégrés d'architecte, audit de sécurité, refactoring et UI design system.
- **Stockage Local & Rétrocompatibilité** : Sauvegarde automatique dans `localStorage`, export & import JSON de votre bibliothèque.

## 🚀 Utilisation

Ouvrir `index.html` dans n'importe quel navigateur moderne. C'est tout.
